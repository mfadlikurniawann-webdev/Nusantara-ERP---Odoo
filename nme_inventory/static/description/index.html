Nusantara ERP - Inventory

Warehouses and an immutable stock move ledger valued at average cost.

Features

  • Receipts, deliveries and transfers between warehouses
  • Stock computed from done moves, negative stock refused
  • Average cost per company updated by every receipt
  • Returns, stock adjustments validated by managers
  • Minimum stock alerts and printable delivery slip

Part of Nusantara Mini ERP, a portfolio project on Odoo 20 Community by M. Fadli Kurniawan. Source code and documentation.
