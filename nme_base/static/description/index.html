Nusantara ERP - Base

Master data and shared document mixins of a compact ERP for Indonesian distributors.

Features

  • Products, hierarchical categories and units of measure
  • Taxes (VAT 11% by default) and payment terms
  • Customer and vendor flags, per-company payment terms, NPWP
  • Company settings: default taxes and payment terms
  • Document mixins: numbering, strict state machine, cancellation with reason, totals

Part of Nusantara Mini ERP, a portfolio project on Odoo 20 Community by M. Fadli Kurniawan. Source code and documentation.
