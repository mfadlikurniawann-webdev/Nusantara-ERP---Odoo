Nusantara ERP - Invoicing

Customer invoices, vendor bills, partial payments and aging.

Features

  • Invoices from delivered goods, bills from received goods
  • Numbering on posting, without gaps
  • Partial payments, overpayment refused
  • Overdue invoices flagged every day, with follow-up activities
  • Receivable and payable aging by bucket

Part of Nusantara Mini ERP, a portfolio project on Odoo 20 Community by M. Fadli Kurniawan. Source code and documentation.
