Nusantara ERP - Reporting

OWL dashboard, analysis reports and Excel export.

Features

  • Dashboard with KPIs and the sales of the last six months
  • Sales analysis with the margin of delivered goods
  • Purchase analysis and stock by warehouse
  • Excel export and PDF aging report

Part of Nusantara Mini ERP, a portfolio project on Odoo 20 Community by M. Fadli Kurniawan. Source code and documentation.
