Nusantara ERP - Sales

Quotations, sales orders, deliveries and customer credit limits.

Features

  • Quotations sent by email with PDF
  • Automatic deliveries, delivered quantity from the stock ledger
  • Credit limit per customer: warn or block
  • Salespeople only see their own orders
  • Kanban, calendar, pivot and graph views

Part of Nusantara Mini ERP, a portfolio project on Odoo 20 Community by M. Fadli Kurniawan. Source code and documentation.
